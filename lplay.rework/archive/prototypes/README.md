# Archived prototypes

These files preserve experiments and drafts. They are not part of the supported LangPlay build or the release quick start.

- `early-transpiler/` contains an earlier C% compiler.
- `oop/`, `replacer/`, and `cmod-drafts/` contain language and syntax sketches.
- `raylib/` contains old game experiments and a vendored Raylib header. A LangPlay Raylib wrapper is no longer planned.
- `misc/` contains unrelated scratch code kept for historical reference.

The active compiler is `../../src/lplay_driver.cpp`. Build artifacts are kept under the ignored `../../build/local-artifacts/` directory, outside this archive. New behavior belongs in the active compiler and language reference before it is described as supported.
